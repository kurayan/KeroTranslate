はじめてのAPIキー設定：Deepgram + Gemini

English · READMEへ戻る

プログラミングは不要です。2つのサービスでキーを作り、KeroTranslateの設定に貼り付けるだけで準備できます。作者の利用環境では、Deepgramの無料クレジットとGeminiの無料利用枠を使った組み合わせで動作確認済みです。

APIって何？ キーは何に使うの？

APIは、アプリから外部サービスへ仕事を頼むための窓口です。KeroTranslateは、配信の音声を文字にする処理や翻訳を外部サービスへ依頼します。APIキーは「あなたのアカウントでそのサービスを使うための専用の鍵」です。ログインパスワードとは別に発行します。

サービスKeroTranslateでの役割用意するもの
Deepgram配信音声を文字にする。画面の STT はこの音声認識のことです。DeepgramのアカウントとAPIキー
Gemini字幕・コメントを翻訳し、re-MTLで元の言語へ訳し直す。GoogleアカウントとGemini APIキー

コメント翻訳だけを使うならGeminiのキーから準備できます。音声字幕も使うときはDeepgramのキーも必要です。この組み合わせでは、タブの音声はDeepgramへ、認識した文章やコメント・訳文はGeminiへ送られます。

1. Deepgramのキーを作る

  1. Deepgram Console（登録・ログイン）を開き、アカウントを作成するかログインします。
  2. 左上のプロジェクトを選び、Settings → API Keys → Create a New API Keyを開きます。プロジェクトはキーや利用量をまとめる入れ物で、初回登録時に作成されます。
  3. 名前を KeroTranslate などにします。Permissions（権限）でロールを選ぶ場合は Member、有効期限は用途に合わせて選び、Create Keyを押します。権限の公式説明
  4. 表示されたキーの文字列をコピーして安全に保管します。キーの全文は再表示できないため、この時点で控えてください。

画面の名前が変わっていたら、Deepgram公式のキー作成手順を参照してください。キーの名前やプロジェクトIDではなく、発行されたキー本体を使います。

2. Geminiのキーを作る

  1. Google AI StudioのAPIキーページを開き、Googleアカウントでログインします。初回は表示された利用条件を確認します。
  2. 初回に自動作成されたキーを使うか、Create API key（APIキーを作成）を選びます。必要に応じて自分のプロジェクトを選択・作成します。
  3. キーをコピーして保管します。既存プロジェクトが見えない場合は Projects → Import projects から追加できます。
  4. 無料枠で試す場合は、そのプロジェクトの料金区分が Free Tier であることを確認します。有料化のための Set up billing を進める必要はありません。

Google公式のキー作成手順 · 無料枠・課金の説明

3. KeroTranslateに貼り付ける

ChromeのKeroTranslateアイコンから Settings & API keys を開き、次のように設定します。メインパネルの歯車からも開けます。

設定欄選ぶ・貼り付けるもの
Speech to textDeepgram
Deepgram API key手順1で作ったDeepgramのキー
Translation + re-MTLGemini
Gemini API key手順2で作ったGeminiのキー
Gemini model ID最初は初期値で試します。利用できないと表示されたら、自分のAPIプロジェクトで使えるモデルIDを確認します。

ストア向け版では、設定上部の音声・文章の送信先の説明を読み、同意欄にチェックしてから Save settings を押します。従来のGitHub Betaでは同意欄がない場合があります。同じChromeプロファイル・同じ拡張のままなら、Chromeを終了してもキーは残ります。設定保存は動作中の字幕取得を停止するので、必要なら開始し直してください。

まずOriginalに短いコメントを入力し、MTLとre-MTLが出るか確認します。字幕は音声の流れているYouTube Liveタブで、メインパネルの Start captions（Chromeから求められた場合は、そのタブでツールバーアイコンを一度開いてから）を押して試します。動作確認にチャット投稿は不要です。

無料で使える範囲と、困ったとき

項目知っておくこと
Deepgramの無料枠無料クレジットを使う方式です。付与条件・残額・有効期限は管理画面で確認してください。使い放題・毎月の補充ではありません。料金・最新条件
Geminiの無料枠Free Tierで対象モデルを上限内で使う方式です。モデル・プロジェクトで利用可否や制限が異なります。料金・現在の制限の確認方法
キーが無効・認証エラーサービスごとの欄を取り違えていないか、全文をコピーしたか、有効期限が切れていないかを確認します。
回数制限・利用枠のエラー各サービスの残量・上限を確認。回数制限なら指定時間を待ち、Request gapの調整も試します。残高不足や利用枠の枯渇は間隔変更だけでは解消しません。
キーをなくした・公開してしまった公式の管理画面で該当キーを削除・無効化し、新しいキーを作って拡張に保存します。

キーはパスワードと同じように扱い、チャット・GitHub・公開スクリーンショットに載せないでください。 Geminiの無料枠では入力・出力がサービス改善に使われる場合があります。Googleの料金・データ利用の説明を確認し、機密情報を入力しないでください。

公式手順・料金条件の確認日：2026-10-17。画面や無料枠は変更されることがあります。動作確認済みの記載は作者の利用環境での結果で、すべてのアカウント・モデルでの動作を保証するものではありません。

最初の時間設定

Request gapは1秒、Caption holdは5秒が初期値です。1秒はリクエスト間の最小間隔で、翻訳が1秒で終わる保証ではありません。回数制限が出るときは2〜6秒など長めにし、各サービスの上限を確認してください。re-MTLにもAPI利用量が発生します。

別のプロバイダを使う場合

このページの順番どおりに試す場合はDeepgramとGeminiの2つだけで十分です。ほかのプロバイダのキーは対応する欄に入力します。全サービスへの登録は不要です。DeepLの公式API入門・DeepSeekの公式API資料を参照してください。APIの契約は各社の一般向けチャット・翻訳サービスの契約とは別の場合があります。

キーを保存・削除するには

キーを入力するのは拡張の設定画面です。この解説ページには入力しません。ストア向け版ではキーと自動解除鍵を同じChromeプロファイル内に保存します。Delete all API keysで保存キーを削除できますが、サービス側のキー自体を無効化するには各社の管理画面で取り消してください。データの取り扱いも確認してください。
