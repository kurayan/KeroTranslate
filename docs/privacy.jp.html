KeroTranslateのプライバシー・データ取扱い

English

最終更新：2026-10-16。運営者：kurayan。このポリシーはChromeウェブストア向けビルドに適用します。ストア公開は準備中です。従来のGitHub配布Beta 0.2には、以下の暗号化保存と明示的同意の仕組みはまだ含まれていません。従来版のAPIキーはChromeのローカル保存領域に平文で保存されます。

取り扱う情報

  • Start captions後のYouTube Liveタブ音声（マイクではありません）。
  • 認識した発話、KeroTranslateへ入力したコメント、編集した翻訳、翻訳結果。コメントは入力を止めると自動翻訳され、INSERTやYouTube投稿より前に送信されます。
  • APIキー、プロバイダ・モデル・言語・表示設定、データ処理への同意。
  • キャプチャ対象タブのIDとURL、状態・エラー、音声量・処理時間・リクエスト数・トークン数などのセッション集計。

送信先

音声は選択したDeepgram / OpenAI / DeepL Voiceへ、字幕原文とコメントは選択したGemini / OpenAI / DeepL / DeepSeekへ直接送ります。逆翻訳では翻訳結果を同じ翻訳プロバイダへ送ります。キーは対応するプロバイダの認証に使います。接続先はIPアドレスなど通常の通信情報も受け取ります。HTTPS/WSSを使用し、OpenAIの音声はHTTPSでの接続交渉後、暗号化されたWebRTCで送信します。

この実装には開発者運営の中継サーバー、広告・アクセス解析の送信先はありません。開発者は拡張経由で音声・下書き・キーを受け取りません。外部サービスの保存、学習利用、料金はアカウント・プランごとの規約に従います。拡張側で外部サービスの記録を削除することはできません。Deepgramにはmip_opt_out=true、OpenAIのテキスト処理にはstore=falseを指定しますが、すべてのプロバイダで保存されないことを保証するものではありません。

保存と削除

APIキーはAES-256-GCMで暗号化し、ランダムに生成した解除用の鍵も同じChromeプロファイル内に保存します。再起動後の入力は不要です。保存領域は信頼された拡張コンテキストに限定し、端末間で同期しません。平文の直接保存は避けますが、保存レコード全体を取得した人は復号できます。端末やプロファイルの侵害から保護する方式ではなく、OSの資格情報保管庫とも異なります。既存平文キーは暗号化保存の読み戻し・復号一致確認後に削除します。全キー削除では解除鍵も削除します。

音声・字幕・コメントはメモリー上で処理し、文字起こし履歴として保存しません。キャプチャ情報と集計はセッション保存領域を使います。Stopで音声処理が止まり、ページを閉じる・再読み込みすると表示中の下書きや字幕が消えます。Delete all API keysで音声と待機処理を止め、保存済みキーと旧形式キーを削除し、処理同意も撤回します。設定は残ります。アンインストールで拡張のローカルデータが削除されます。キー自体の失効やサービス側記録の削除は各プロバイダで行ってください。

利用者の操作と目的

通信機能の開始前に設定画面で同意します。音声認識と翻訳の送信先を別々に選べます。INSERTはYouTubeの入力欄への挿入だけで、自動投稿しません。利用者自身が投稿したコメントにはYouTubeの規約が適用されます。

扱う情報は字幕・コメント翻訳機能の提供に用い、広告、販売、無関係なプロファイリングには使いません。Google API由来の情報は、Limited Useを含むChromeウェブストアのユーザーデータポリシーに従う方針です。

問い合わせ: 公開リポジトリのIssue。APIキーや非公開の音声・文章を投稿しないでください。

公式サイトのアクセス解析（任意）

サイト解析についての更新日：2026-10-25。この項目は公式サイトのみが対象です。Chrome拡張機能にはGoogle Analyticsを追加していません。

同意した場合のみGoogle Analytics 4（G-SBMMGFZGFQ）を読み込み、ページ閲覧とChromeウェブストアへのリンクのクリックを計測します。Googleにはページ・ブラウザー・端末情報、Cookie識別子、IPアドレスなどの通信情報が送られます。広告シグナルと広告のパーソナライズは無効にしています。サイトのURLにAPIキーや個人情報を入力しないでください。

拒否時はGoogleの解析タグを読み込みません。各ページ下部の「アクセス解析の設定」からいつでも同意を撤回でき、以後の解析を停止して当サイトの解析用Cookieを削除します。撤回前に収集されたデータは、撤回操作では削除されません。解析Cookieの有効期間は更新なしの90日です。同意・拒否の選択は、変更またはサイトデータの削除までブラウザーに保存します。保存できない環境では、そのページ内のみ有効です。

拡張機能の音声・コメント・APIキー・ライセンス情報をサイト解析に送ることはありません。GoogleプライバシーポリシーとGoogleによるパートナーサイトの情報利用もご確認ください。ホスティング元のGitHub Pagesは、解析への同意とは別に、配信とセキュリティのためIPアドレス等の通信情報を処理する場合があります。GitHubのプライバシー声明をご覧ください。
